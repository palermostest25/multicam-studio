Help & diagnostics
Can’t see an external drive? Connect it, then find it in the file browser’s shortcuts (Volumes on macOS, drive letters on Windows). In Docker, mount the folder into the container first. If the system asks to allow file access, grant access to the folders you want to use.
Can’t render? Check the tools above, use an output folder you can write to, and leave space on the working drive for temporary video files.
Need to share a problem? Download a diagnostic report. Review it before sending it to someone else; it may contain local folder paths.
Finished for now? Quit stops this local workspace. Your saved projects and exports remain available.
